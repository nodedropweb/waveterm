Waves Konfigurationsdateien befinden sich unter `~/.config/waveterm/`.

Die Hauptkonfigurationsdatei ist `settings.json` (`~/.config/waveterm/settings.json`).

Die Datei ist als weitgehend flaches JSON strukturiert. Statt Unterobjekten nutzen wir bevorzugt
":" als Ebenentrenner.

:::info

Der einfachste Weg, deine Konfigurationsdateien zu bearbeiten, ist der Befehl wsh editconfig, der deine Wave-Konfigurationsdatei in unserem integrierten Vorschau-Editor öffnet.

```
wsh editconfig
```

:::

## Auflösung von Umgebungsvariablen

Um Secrets nicht direkt in Konfigurationsdateien zu speichern, unterstützt Wave die Auflösung von Umgebungsvariablen über die Syntax `$ENV:VARIABLE_NAME` oder `$ENV:VARIABLE_NAME:fallback`. Dies funktioniert für jeden String-Wert in jeder Konfigurationsdatei (settings.json, presets.json, ai.json usw.).

```json
{
  "ai:apitoken": "$ENV:OPENAI_APIKEY",
  "ai:baseurl": "$ENV:AI_BASEURL:https://api.openai.com/v1"
}
```

## WebBookmarks-Konfiguration

Mit WebBookmarks kannst du Weblinks mit anpassbaren Anzeigeeinstellungen speichern und verwalten. Die Lesezeichen werden in einer JSON-Datei (`bookmarks.json`) als Schlüssel-Wert-Map gespeichert, wobei der Schlüssel (`id`) ein beliebiger Bezeichner für das Lesezeichen ist. Üblicherweise sollten deine IDs mit "bookmark@" beginnen. Im Web-Widget kannst du deine Lesezeichen mit <Kbd k="Cmd:o"/> aufrufen.

### Lesezeichen-Struktur

Jedes Lesezeichen folgt dieser Struktur (nur `url` ist erforderlich):

```json
{
  "url": "https://example.com",
  "title": "Example Site",
  "iconurl": "https://example.com/custom-icon.png",
  "display:order": 1
}
```

### Felder

| Feld         | Typ    | Beschreibung                                                                                                       |
| ------------- | ------- | ----------------------------------------------------------------------------------------------------------------- |
| url           | string  | **Erforderlich.** Die URL des Lesezeichens.                                                                            |
| title         | string  | **Optional.** Ein Anzeigetitel für das Lesezeichen.                                                                   |
| icon          | string  | **Optional, selten genutzt.** Überschreibt das Standard-Favicon mit einem Icon-Namen.                                       |
| iconcolor     | string  | **Optional, selten genutzt.** Legt eine benutzerdefinierte Farbe für das angegebene Icon fest.                                            |
| iconurl       | string  | **Optional.** Gibt eine benutzerdefinierte Icon-URL an, nützlich, wenn das Favicon nicht korrekt ist (z. B. für Kompatibilität mit dem Dark Mode). |
| display:order | float64 | **Optional.** Legt die Reihenfolge fest, in der Lesezeichen erscheinen.                                                        |

### Beispiel `bookmarks.json`

```json
{
  "bookmark@google": {
    "url": "https://www.google.com",
    "title": "Google"
  },
  "bookmark@claude": {
    "url": "https://claude.ai",
    "title": "Claude AI"
  },
  "bookmark@wave": {
    "url": "https://waveterm.dev",
    "title": "Wave Terminal",
    "display:order": -1
  },
  "bookmark@wave-github": {
    "url": "https://github.com/wavetermdev/waveterm",
    "title": "Wave Github",
    "iconurl": "https://github.githubassets.com/favicons/favicon-dark.png"
  },
  "bookmark@chatgpt": {
    "url": "https://chatgpt.com",
    "iconurl": "https://cdn.oaistatic.com/assets/favicon-miwirzcw.ico"
  },
  "bookmark@wave-pulls": {
    "url": "https://github.com/wavetermdev/waveterm/pulls",
    "title": "Wave Pull Requests",
    "iconurl": "https://github.githubassets.com/favicons/favicon-dark.png"
  }
}
```

### Verhalten

- Ist `iconurl` gesetzt, wird das Icon von der angegebenen URL statt vom Standard-Favicon der Seite geladen.
- Lesezeichen werden nach `display:order` sortiert (falls angegeben), sonst nach ID.
- `icon` und `iconcolor` werden selten benötigt, da standardmäßig das Favicon der Seite geladen wird.
- Favicons werden alle 24 Stunden aktualisiert

## Terminal-Theming

Benutzerdefinierte Terminal-Themes befinden sich unter `~/.config/waveterm/termthemes.json`.

Diese JSON-Datei ist als Objekt strukturiert, wobei jeder Unterschlüssel ein Theme definiert.
Themes werden angewendet, indem du mit der rechten Maustaste auf die Kopfzeile des Terminals klickst und einen Eintrag aus dem Untermenü "Themes" auswählst. Alternativ können sie auf
den Metadaten-Schlüssel `term:theme` des Blocks angewendet werden. Dabei wird der JSON-Schlüsselwert als Bezeichner genutzt. Beachte, dass für beste Konsistenz alle Farben im Format "#rrggbb" oder "#rrggbbaa" (aa = Alphakanal für Transparenz) angegeben werden sollten.

```
wsh setmeta this term:theme="default-dark"
```

Hier ist ein Beispiel für die Definition eines vollständigen Terminal-Themes. Alle integrierten Themes sind hier definiert: https://github.com/wavetermdev/waveterm/blob/main/pkg/wconfig/defaultconfig/termthemes.json (wenn du ein beliebtes Terminal-Theme hinzufügen möchtest, reiche bitte einen PR ein!)

```json
{
  "default-dark": {
    "display:name": "Default Dark",
    "display:order": 1,
    "black": "#757575",
    "red": "#cc685c",
    "green": "#76c266",
    "yellow": "#cbca9b",
    "blue": "#85aacb",
    "magenta": "#cc72ca",
    "cyan": "#74a7cb",
    "white": "#c1c1c1",
```

## Anpassbare systemweite globale Tastenkombination

Wave erlaubt es, eine benutzerdefinierte globale Tastenkombination festzulegen, um von überall auf deinem Computer dein zuletzt genutztes Fenster zu öffnen. Diese heißt `"app:globalhotkey"` in der `settings.json`-Datei und besteht aus einer Reihe von Tastennamen, getrennt durch das Zeichen `:`.

### Beispiele

Als praktisches Beispiel: Angenommen, du möchtest `F5` als globale Tastenkombination nutzen. Dann kannst du einfach den Wert von `"app:globalhotkey"` auf `"F5"` setzen und Wave neu starten, damit dies deine globale Tastenkombination wird.

Als weniger praktisches Beispiel: Angenommen, du nutzt die Kombination der Tasten `Ctrl`, `Option` und `e`. Dann wäre der Wert für diese Tastenkombination `"Ctrl:Option:e"`.

### Erlaubte Tastennamen

Wir unterstützen folgende Tastennamen:

- `Ctrl`
- `Cmd`
- `Shift`
- `Alt`
- `Option`

- Buchstaben `a` bis `z`
- F-Tasten `F1` bis `F20`
- Soft-Tasten `Soft1` bis `Soft4`. Diese sind im Wesentlichen identisch mit `F21` bis `F24`.
- Leertaste, dargestellt als `Space` oder ein wörtliches Leerzeichen &nbsp;<code>&nbsp;</code>
- `Enter` (auf dem Mac als "Return" beschriftet)
