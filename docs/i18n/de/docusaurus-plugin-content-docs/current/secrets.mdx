# Secrets

<VersionBadge version="v0.13" noLeftMargin={true} />

Wave Terminal bietet einen sicheren Weg, sensible Informationen wie Passwörter, API-Schlüssel und Token zu speichern. Secrets werden verschlüsselt im nativen Schlüsselbund deines Systems gespeichert (macOS Keychain, Windows Credential Manager oder Linux Secret Service), sodass deine sensiblen Daten geschützt bleiben.

## Warum Secrets nutzen?

Mit Secrets in Wave Terminal kannst du:

- **SSH-Passwörter speichern** - Automatische Authentifizierung bei SSH-Verbindungen, ohne Passwörter einzutippen
- **API-Schlüssel verwalten** - API-Token, Schlüssel und Zugangsdaten sicher aufbewahren
- **Über Sitzungen hinweg teilen** - Auf deine Secrets aus jedem Terminal-Block oder jeder Remote-Verbindung zugreifen
- **Klartext-Speicherung vermeiden** - Niemals sensible Daten in Konfigurationsdateien oder Skripten speichern

## Die Secrets-Oberfläche öffnen

Es gibt mehrere Wege, auf die Secrets-Verwaltungsoberfläche zuzugreifen:

1. **Über die Widget-Leiste** (empfohlen):
   - Klicke auf das Einstellungssymbol **<i className="fa-gear fa-solid fa-sharp"/>** in der Widget-Leiste
   - Wähle **Secrets** aus dem Menü

2. **Über die Kommandozeile:**
   ```bash
   wsh secret ui
   ```


Die Secrets-Oberfläche bietet eine grafische Oberfläche zum Anzeigen, Hinzufügen, Bearbeiten und Löschen von Secrets.

## Secrets über die CLI verwalten

Wave Terminal bietet eine vollständige CLI zur Verwaltung von Secrets aus jedem Terminal-Block:

```bash
# Alle Secret-Namen auflisten (nicht die Werte)
wsh secret list

# Einen bestimmten Secret-Wert abrufen
wsh secret get MY_SECRET_NAME

# Ein Secret setzen (Format: name=value, keine Leerzeichen um das =)
wsh secret set GITHUB_TOKEN=ghp_xxxxxxxxxx
wsh secret set DB_PASSWORD=super_secure_password

# Ein Secret löschen
wsh secret delete MY_SECRET_NAME
```

## Regeln für Secret-Namen

Secret-Namen müssen dem Muster entsprechen: `^[A-Za-z][A-Za-z0-9_]*$`

Das bedeutet:
- Muss mit einem Buchstaben beginnen (A-Z oder a-z)
- Darf nur Buchstaben, Zahlen und Unterstriche enthalten
- Darf keine Leerzeichen oder Sonderzeichen enthalten

**Gültige Namen:** `MY_SECRET`, `ApiKey`, `ssh_password_1`
**Ungültige Namen:** `123_SECRET`, `my-secret`, `secret name`

## Secrets mit SSH-Verbindungen nutzen

<VersionBadge version="v0.13" />

Secrets können genutzt werden, um Passwörter für SSH-Verbindungen automatisch bereitzustellen, sodass du Passwörter nicht wiederholt eintippen musst.

### In connections.json konfigurieren

Füge das Feld `ssh:passwordsecretname` zu deiner Verbindungskonfiguration hinzu:

```json
{
    "myserver": {
        "ssh:hostname": "example.com",
        "ssh:user": "myuser",
        "ssh:passwordsecretname": "SERVER_PASSWORD"
    }
}
```

Speichere dann dein Passwort als Secret:

```bash
wsh secret set SERVER_PASSWORD=my_actual_password
```

Wenn Wave sich nun mit `myserver` verbindet, nutzt es automatisch das Passwort aus deinem Secret-Speicher, anstatt dich danach zu fragen.

### Vorteile

- **Sicherheit**: Passwort verschlüsselt im System-Schlüsselbund gespeichert
- **Komfort**: Kein Eintippen von Passwörtern für jede Verbindung nötig
- **Flexibilität**: Passwörter aktualisieren, indem du das Secret änderst, nicht die Konfiguration

## Sicherheitsaspekte

- **Verschlüsselte Speicherung**: Secrets werden verschlüsselt in deinem Wave-Konfigurationsverzeichnis gespeichert. Der Verschlüsselungsschlüssel selbst wird durch den sicheren Zugangsdatenspeicher deines Betriebssystems geschützt (macOS Keychain, Windows Credential Manager oder Linux Secret Service).

- **Kein Klartext**: Secrets werden niemals unverschlüsselt in Logs oder zugänglichen Dateien gespeichert.

- **Zugriffskontrolle**: Secrets sind ausschließlich für Wave Terminal zugänglich.


## Speicher-Backend

Wave Terminal erkennt automatisch das passende Secret-Speicher-Backend für dein Betriebssystem und nutzt es:

- **macOS**: Nutzt die macOS Keychain
- **Windows**: Nutzt den Windows Credential Manager
- **Linux**: Nutzt die Secret Service API (freedesktop.org-Spezifikation)

:::warning Linux-Secret-Speicher
Unter Linux benötigt Wave ein kompatibles Secret-Service-Backend (typischerweise GNOME Keyring oder KWallet). Diese sind normalerweise mit deiner Desktop-Umgebung vorinstalliert. Wird kein kompatibles Backend erkannt, kannst du keine Secrets setzen, und die Oberfläche zeigt eine Warnung an.
:::

## Fehlerbehebung

### "No appropriate secret manager found"

Dieser Fehler tritt unter Linux auf, wenn kein kompatibles Secret-Service-Backend verfügbar ist. Installiere GNOME Keyring oder KWallet und stelle sicher, dass der Secret Service läuft.

### Secret nicht gefunden

Stelle sicher, dass der Secret-Name korrekt geschrieben ist (Namen unterscheiden Groß-/Kleinschreibung) und dass das Secret existiert:

```bash
wsh secret list
```

### Zugriff verweigert unter Linux

Der Secret Service verlangt möglicherweise, dass du deinen Schlüsselbund entsperrst. Das passiert normalerweise nach dem Login. Konsultiere die Dokumentation deiner Desktop-Umgebung zur Schlüsselbundverwaltung.
