Hier ist die Liste der Standard-Tastenkombinationen in Wave, unterteilt in Abschnitte.
Manche Tastenkombinationen sind immer aktiv. Andere gelten nur für bestimmte Blocktypen.

Beachte, dass dies die macOS-Tastenkombinationen sind (mit "Cmd"). Für Windows und Linux
ersetze "Cmd" durch "Alt" (beachte, dass "Ctrl" sowohl unter Mac, Windows als auch Linux "Ctrl" ist).

Chords werden mit einem + zwischen den Tasten dargestellt. Du hast 2 Sekunden Zeit, um nach der ersten Taste die zweite Chord-Taste zu drücken. Escape nach der ersten Chord-Taste ist immer wirkungslos.

## Tastenkombinationen für die Dateivorschau

| Taste                                       | Funktion                                                                                           |
| ----------------------------------------- | -------------------------------------------------------------------------------------------------- |
| <Kbd k="[text]"/>                         | Jedes normale Zeichen (z. B. "a", "b") filtert die Dateiliste                                    |
| <Kbd k="Escape"/>                         | Setzt den Filter zurück                                                                                  |
| <Kbd k="ArrowUp"/> / <Kbd k="ArrowDown"/> | Dateiauswahl nach oben/unten ändern                                                                      |
| <Kbd k="Enter"/>                          | Aktuell ausgewählte Datei/Verzeichnis öffnen                                                         |
| <Kbd k="Cmd:ArrowUp"/>                    | Ein Verzeichnis "nach oben" bewegen (übergeordnetes Verzeichnis)                                                           |
| <Kbd k="Cmd:ArrowLeft"/>                  | Zurück, zur zuvor ausgewählten Datei/Verzeichnis wechseln                                               |
| <Kbd k="Cmd:ArrowRight"/>                 | Vorwärts (Gegenteil von Zurück)                                                                         |
| <Kbd k="Cmd:o"/>                          | Eine neue Datei öffnen (akzeptiert relative Pfade zum aktuellen Verzeichnis)                                  |
| <Kbd k="Cmd:s"/>                          | Wenn der Datei-Editor geöffnet ist, Datei speichern                                                                |
| <Kbd k="Cmd:e"/>                          | Für Dateien, die in Vorschau oder bearbeitet werden können (Markdown, CSVs), zwischen Vorschau- und Bearbeitungsmodus wechseln |
| <Kbd k="Cmd:r"/>                          | Wenn der Datei-Editor geöffnet ist, Änderungen verwerfen                                                           |

## Anpassbare systemweite globale Tastenkombination

Wave erlaubt es, eine benutzerdefinierte globale Tastenkombination festzulegen, um von überall auf deinem Computer aus dein zuletzt genutztes Fenster zu fokussieren. Weitere Informationen dazu findest du in der [Konfigurationsdokumentation](./config#customizable-systemwide-global-hotkey).
